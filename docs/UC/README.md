# Sơ đồ Use Case EasyRetail

Tất cả sơ đồ trong thư mục này dùng định dạng đen–trắng và mô tả hệ thống quản
lý bán hàng tại quầy.

- Bản SVG nằm trong `docs/UC/svg/`.
- Bản PNG xem nhanh nằm trong `docs/UC/png/`.
- Mã XML `.drawio` chỉnh sửa được nằm trong `docs/UC/drawio/`.
- Không tạo PDF.
- `use-case-tong-quat-easyretail`: sơ đồ use case tổng quát.
- `UC01-dang-nhap-dang-xuat`: sơ đồ chi tiết UC01.
- `UC01-dang-nhap-dac-ta.md`: bảng đặc tả chi tiết use case đăng nhập.
- `UC02-ban-hang-tai-quay`: sơ đồ chi tiết UC02.
- `UC03-tra-cuu-don-hang`: sơ đồ chi tiết UC03.
- `phan-ra-nhan-vien`: sơ đồ use case phân rã theo tác nhân Nhân viên.
- `phan-ra-quan-tri-vien`: sơ đồ use case phân rã theo tác nhân Quản trị viên.

Quy ước tác nhân: máy quét USB HID được xem là thiết bị nhập liệu như bàn phím,
không phải actor độc lập. payOS và Google Gemini là actor phụ vì chúng là hệ
thống ngoài trao đổi dữ liệu với EasyRetail qua API.
