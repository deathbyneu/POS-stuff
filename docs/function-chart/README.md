# Biểu đồ chức năng EasyRetail

- `01-bieu-do-chuc-nang-easyretail.svg`: bản vector có thể chèn trực tiếp vào Word.
- `01-bieu-do-chuc-nang-easyretail.drawio`: bản nguồn chỉnh sửa từng khối và đường nối bằng diagrams.net/draw.io.
- `01-bieu-do-chuc-nang-easyretail.png`: bản ảnh xem nhanh.
- `01-bieu-do-chuc-nang-easyretail.pdf`: bản PDF để ghép vào báo cáo.

Biểu đồ được đối chiếu với route giao diện, API, mô hình dữ liệu và phân quyền
hiện có. Đây là biểu đồ phân rã chức năng theo nhóm người dùng, khác với sơ đồ
use case UML trong `docs/use-cases/`.
