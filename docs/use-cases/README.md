# Bộ sơ đồ use case NEU SelfPOS

- `01-tong-quan`: sơ đồ tổng quan toàn hệ thống và các tác nhân.
- `02-self-checkout`: luồng tự chọn, tự quét và thanh toán QR tại kiosk.
- `03-quan-tri-va-ban-hang`: chức năng của Nhân viên và Quản trị viên.
- `USE-CASE-SPEC.md`: bảng đặc tả 17 use case và quy tắc nghiệp vụ.
- `NEU-SelfPOS-Use-Case.pdf`: bản PDF ba trang để nộp hoặc chèn vào báo cáo.
- `NEU-SelfPOS-Use-Case-Spec.docx`: bản Word đặc tả để sửa và ghép vào báo cáo.
- `NEU-SelfPOS-Use-Case-Spec.pdf`: bản PDF đặc tả 17 use case.
- `NEU-SelfPOS-Use-Case-Full.pdf`: bản đầy đủ gồm ba sơ đồ và toàn bộ đặc tả.

Các file SVG là bản nét vector, có thể chèn trực tiếp vào Word hoặc mở bằng
trình chỉnh sửa vector. File PNG phù hợp để kéo-thả nhanh vào tài liệu.

Ký hiệu:

- Đường liền: tác nhân tham gia use case.
- `<<include>>`: chức năng bắt buộc được use case chính gọi.
- `<<extend>>`: nhánh chỉ xảy ra khi có điều kiện.
- Mũi tên tam giác rỗng: tác nhân kế thừa quyền.
